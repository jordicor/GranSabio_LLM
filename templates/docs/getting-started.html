Authentication

The BioAI Unified Engine is currently configured for internal use. No API keys are required for client requests.

Server output and storage

Configure the process in .env: LOG_MODE=normal|quiet|verbose controls operational output. Quiet retains warnings, errors and storage recovery notices, while suppressing routine output and HTTP access logs.

LOG_BACKEND=local|postgresql independently chooses operational log storage. PostgreSQL requires explicit LOG_DATABASE_URL and LOG_INSTANCE_ID. Debugger history has separate DEBUGGER_* settings; switching backend preserves existing SQLite history.

These are server settings, not /generate request fields. Quiet does not reduce request progress, debugger capture or model work. See the storage and recovery guide for profiles, limits, retention, status and shutdown guarantees.

Base URL

http://localhost:8000
